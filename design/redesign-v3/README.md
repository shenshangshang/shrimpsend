# 虾传 · 全页面 UI 设计册

日期：2026-09-21。状态：**用户已确认，Flutter、Web 与官网已实现（鸿蒙暂缓）**。

打开 `index.html` 浏览设计册。17 张画板包含 69 个页面与状态画面；这是同一套方向的完整展开，不是 17 个候选方案。支持目录、搜索、翻页和放大。画面内的业务按钮是静态效果展示。

## 设计目标

- 传输、文件、设置作为三个稳定的一级入口。桌面使用窄导航栏，手机使用底部导航。
- 设备会话是日常传输的中心；文字、文件和进度放在一起，发送对象始终明确。
- 设备连接、设备会员授权、购买账号保持三个独立概念。登录不自动建立连接、不自动授权、不自动同步历史。
- 接收位置默认是平台下载目录，支持自定义目录；文件直接落到目标位置。浏览器受能力和权限约束时明确说明实际行为。
- 断线恢复保留原任务；错误提示紧邻受影响的任务或字段，并提供明确的处理入口。
- 公共信令、单向网络和备用中转等复杂选项放入连接详情或配置页面。
- 账号仅在购买、名额管理等场景出现，不打断免登录与离线传输。

## 统一实现规范

| 项目 | 规范 |
| --- | --- |
| 一级导航 | 传输 / 文件 / 设置；桌面设置固定在底部 |
| 设置二级导航 | 本机设置 / 本机授权 / 会员与名额 / 账号 / 帮助 |
| 本机设置内部 | 通用 / 接收与保存 / 外观 / 语言 / 字体 / 快捷键 |
| 文件二级导航 | 本机文件 / 云端文件 / 最近使用 / 收藏 / 传输任务 / 连接设置；按当前端能力呈现 |
| 桌面导航尺寸 | 一级栏 72px，二级栏 220–264px，页面内容最大宽度按场景约 720–960px |
| 字体 | 中文系统无衬线，英文系统无衬线；正文 14–16px，辅助信息 12px，页面标题 22–26px |
| 间距 | 4px 基础单位，主要分组 24–32px；移动端边距 20px，触控区域至少 44px |
| 形状 | 输入框与按钮 8px 圆角；卡片/弹层 12px；优先留白和分隔线 |
| 浅色 | 背景 #FBFCFB；次级面 #F3F4F1；正文 #202823；主操作 #20735C |
| 深色 | 背景 #181D1B；次级面 #202723；正文 #ECF2EE；辅助文字 #A5B3AA；强调 #6CCDA9 |
| 图标与品牌 | 延续可识别的虾形标志，统一单色应用方式；功能图标统一使用同一套线性图标，禁止混用粗细 |
| 文件任务 | 只保留一个当前任务实例；连接中断→恢复时更新同一张卡片，不重复添加同一文件任务 |
| 授权码 | 单一可粘贴输入，视觉分成六格；大写字母和数字。与设备连接码使用不同标签 |
| 任务列表 | 「进行中」只显示活跃/暂停任务；完成任务进入「已完成」，不混入当前筛选结果 |
| 高级连接 | 默认自动选择；普通会话不常驻协议选择器，手动配置只在详情中出现 |

效果图用于确认视觉和布局，生成图中个别导航、图标或文字细节在实现时以以上统一规范为准。画板 14 的断线与恢复两张卡片是前后状态示意，不表示产品同时保留两个任务。
