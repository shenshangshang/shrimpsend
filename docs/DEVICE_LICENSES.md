# 设备授权实施说明

实施日期：2026-09-20 至 2026-09-21。决策来源：[设备授权会员模型](DEVICE_AUTHORIZATION_MODEL.md)。

## 用户流程

1. 购买者登录一次，在「设备会员」购买原有套餐、续费或增购名额；登录本身不占授权名额。
2. 点击「生成授权码」，短暂预留一个名额。显示六位大写字母/数字码、二维码、到期时间；凭证只显示这一次。
3. 其他设备进入「本机授权」，无需登录。手输短码后，购买端核对设备名称、平台、设备 ID 并确认；扫码或粘贴完整授权链接后，目标设备点击授权即可完成。
4. 已授权设备独立使用设备消息和信令服务。购买者可改备注、解除授权并把名额分给新设备；目标设备也可自行解除。
5. 退出账号保留设备授权和本地历史。解除配对只影响设备连接；解除会员授权只影响在线商业额度。

页面：Web `/authorize`；购买者管理 `/settings/membership`。Mac 设置中的「本机授权」同时提供本机授权与已登录购买者的名额管理。

授权状态：`FREE` 免费、`AUTHORIZED` 有效、`EXPIRED` 会员到期、`SUSPENDED` 套餐缩减后名额不足、`REVOKED` 已解除。正常到期保留归属，续费自动恢复；名额不足按最早授权时间、设备 ID 稳定排序保留，购买者可解除不需要的设备调整顺序。本机文件、局域网传输、已经建立的直接传输不依赖授权刷新。

## 身份与权益边界

- Web 只有传输页建立实时连接，会员、设置和授权页面不会接走消息。两端补充消息接收确认；心跳超时会关闭失效连接并重连。
- 新传输统一使用本机 `device_access` JWT。购买账号既不能凭登录状态绕过设备额度，也不能代领其他设备的实时令牌或待收消息。
- 消息只投递到具体设备；会员归属不建立配对，不共享历史、文件、S3/WebDAV 凭据。
- 新 Web 历史只在本浏览器的 IndexedDB 保存元数据，不保存文件字节。Mac 的 SQLite 记录和续传状态归本机；既有本地 1:1 历史迁移为稳定设备会话，退出购买账号后仍可查看。
- 直接接收仍写入默认下载目录或用户选择的目标目录；授权代码不进入文件字节路径。
- 现有支付宝、RevenueCat、Stripe 权益仍是名额和期限的来源，未改变价格、支付渠道或收费。自有 S3/WebDAV 配置与托管云上传的现有账号能力保留，**本轮设备授权提供的是设备消息/信令权益，不自动转授购买者的云存储密钥或无限中转带宽**。

## 六位码、唯一性与并发

字符集 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`，自动转大写并忽略空格/连字符。首字符为发行数据库的命名空间，后五字符安全随机生成，每个命名空间有 33,554,432 种组合；需要独立数据库之间不重复时，必须分配互不相同的命名空间。同一数据库的所有实例使用相同命名空间和密钥。

数据库唯一索引是最终约束，碰撞后整笔事务回滚并有界重试。已兑换、过期和取消的码保留 HMAC 指纹，不重用；独立密钥不能随 JWT 密钥轮换，迁移数据库时也必须保留。不同数据库共用同一命名空间不能保证不重复，新增区域必须先分配命名空间，空间接近耗尽时应迁移到更长码。

- 默认有效期 600 秒、一次使用。二维码另含 256 位随机凭证，放在 URL fragment 中；页面读取后移除 fragment，授权页禁用分析上报与自动链接追踪。
- 所有变更先锁购买者，再锁设备凭据与授权关系；签发预留、认领、确认、兑换和换机由事务保证。关闭请求范围的持久化会话，避免锁等待后读到兑换前缓存的实体。
- 同设备重试同一次已成功兑换返回当前状态；另一设备不能再次使用。其他购买者不能覆盖未解除的归属。
- 手输码会等待购买者确认。猜中短码不能直接取得会员名额；购买者应核对设备 ID，遇到不认识的申请可以撤销重建。
- 激活按全局、来源地址、设备同时限频；签发按账号限频，换机按账号限频。计数保存在共享数据库，服务重启和多实例不会清空。计数初始化使用原子 upsert，避免 MySQL 并发下共享锁升级的死锁。
- 审计表记录签发、认领、授权、改名、撤销、账号删除，不记录授权明文、二维码凭证或文件内容。

## 配额与连接稳定性

免费设备原有轻量消息额度为 90 次/分钟，普通信令/新协商为 600 次/分钟。已准入的 WebRTC 会话每个端点另有 15 分钟内最多 256 条后续协商、取消和恢复预算，避免新连接额度耗尽时卡住当前 ICE 协商。两端按自己的授权判断，不因与会员设备连接而获得全局无限额度。

有效授权不扣正常消息/信令商业额度，所有设备仍保留每分钟 6,000 次异常请求保护。文件直传不限速。共享计数使用带索引的数据库记录，不承载文件字节；更大规模部署可替换为共享内存服务，保留相同准入和撤销语义。

## 独立配置

根目录 `.env.local-deploy` 是本机配置，`.env.production.example` 是可提交模板。`docker/production.yml` 在镜像外挂载，不把密钥打入镜像。

| 变量 | 用途 |
|---|---|
| `DEVICE_LICENSE_SECRET` | 独立、至少 32 字符的长期 HMAC 密钥；必须备份 |
| `DEVICE_LICENSE_NAMESPACE` | 一位发行前缀；建议国内 C、国际 G、本地 L |
| `DEVICE_LICENSE_CODE_TTL_SECONDS` | 码有效期，默认 600 秒 |
| `DEVICE_LICENSE_REPLACEMENTS_PER_DAY` | 每账号每日解除/换机频率，默认 20 |
| Flutter `WEB_URL` | 授权二维码指向的 Web 站点，位于 `.local/flutter.json` |

生产与本地应使用不同的数据库、密钥和命名空间。部署前执行数据库备份；数据库自动建表关闭时，执行 `backend/scripts/migration-device-licenses.sql`。

## 兼容与迁移

首个新版实例启动时，在一个事务内执行一次迁移：已有账号设备连接转为显式配对；已有非免费会员的活跃登录设备转为旧设备授权。原先多个 Web 安装合算一台的既有设备保留额外名额，避免升级批量停用。迁移完成标记与数据一起提交，多实例启动不会重复导入。后续购买或登录不自动授权。

旧账号历史表和旧账号登录管理仍保留，现代设备传输不写入账号历史。**只会使用账号 JWT 的旧传输客户端需要升级**：旧 `/send` URL 保留，但要求设备 JWT；不保留能冒充其他设备或越权读邮箱的账号兼容路径。最近两天已采用设备会话的主线客户端接入新版后可继续使用。

## 本地验证

本地测试购买者由 `python3 scripts/seed-local-license-qa.py` 准备，只能连接项目的本地 Docker context 与容器。凭据在忽略的 `.local/license-qa.json`，数据库备份在 `.local/backups/`，均为 `0600`。测试不会发送邮件或创建真实支付。当前保留了 Web、另一浏览器来源和 Mac 的三个本地演示授权。运行 `scripts/smoke-device-licenses.py` 需要此专用账号有三个空闲名额；先在其会员页解除演示授权，脚本只清理自己创建的临时授权。实际验收结果记录在 [授权测试记录](testing/2026-09-20-device-licenses.md)。
