# 开始使用虾传

虾传把文件和文字放在同一个设备会话里。打开应用，连接另一台设备，就可以开始发送；无需先注册账号。

## 连接另一台设备

在「传输」中选择「连接设备」。扫描对方显示的二维码，或粘贴设备 ID、配对链接。连接成功后，设备会留在列表里，下次直接选择即可。

原生客户端会发现同一局域网中的设备。浏览器无法主动广播发现，可使用配对入口连接；浏览器页面应在有网络时先打开。

## 发送文字、文件和图片

选择目标设备，在输入框输入文字，或通过文件、图片按钮选择内容。桌面端也可以把文件拖入会话，再点击发送。不同设备的待发送内容分别保留，切换页面不会主动中断正在进行的任务。

默认优先选择可用的直接传输方式。需要排查连接时，打开会话右上角的「检查连接」；日常使用无需理解网络协议。

## 离线、单向网络与断点续传

两台原生设备在局域网内可直接收发，无需账号和公网信令。跨网络发现、协商与投递依赖相应在线服务。

如果一端无法被另一端直接访问，虾传会尝试反向拉取等可用通道。连接结果取决于两侧实际网络条件；双方都无法建立可用通道时，界面会提示检查连接。

支持续传的任务在中断后保留进度。恢复连接后，可从会话或「文件 → 传输任务」继续原任务。不要删除正在接收的文件或修改来源文件，否则可能需要重新发送。

## 接收到哪里

接收文件直接写入目标目录，默认使用系统下载目录；可在「设置 → 本机设置 → 接收与保存」选择其他目录。同名文件使用新的文件名，避免覆盖已有内容。

浏览器的目录能力取决于浏览器支持。支持目录授权时，可以选择并直接写入目标文件夹；其他浏览器使用系统下载功能，保存位置由浏览器设置决定。iOS、Android 的文件提供器受系统权限约束，界面会说明实际保存位置。

「文件」中可查看本机文件、最近记录、收藏和传输任务。查看或发送文件需要对当前路径仍有访问权限；记录存在不代表原文件仍在。

## 使用自己的云端存储

在「文件 → 云端文件」添加 WebDAV 连接，填写地址与凭据后测试连接。新连接属于当前设备，文件直接在设备与存储服务之间传输，不要求登录虾传账号。桌面客户端使用系统安全存储保管凭据；Web 端密码仅保留在当前页面运行期间，刷新后需要重新输入。

浏览器连接 WebDAV 时，存储服务必须允许对应跨域请求。无法调整服务配置时，可使用原生客户端。S3 通道另有连接与服务配置入口，具体可用性以界面显示为准。

## 会员和设备授权

账号用于购买会员、分配设备名额和查看订单。只需要在负责购买的那台设备登录账号，其他设备无需登录同一账号。

在「设置 → 会员与名额 → 设备名额」生成一次性授权码。在目标设备的「本机授权」输入六位大写字母与数字组合，或扫描授权二维码。手动输入授权码后，购买方需要核对并确认设备。

授权成功后，后台记录设备归属，服务权益按设备生效。设备 ID、文件、会话和历史独立于账号；授权不会共享账号文件。解除授权后可重新分配名额，已下载文件保留。会员到期后仍可使用本机文件和离线传输。

## 搜索与问题反馈

搜索只检索这台设备已有的文本与文件记录。其他设备的历史不会因为登录同一账号而出现在这里。

在「设置 → 帮助」可以查看版本、运行日志和反馈入口。提交反馈前请检查内容，避免附带密码、授权链接或私人文件。
