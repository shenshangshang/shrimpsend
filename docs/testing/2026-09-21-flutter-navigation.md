# Flutter 固定导航修复

用户反馈：传输、文件和设置切换时，整个页面连同左侧导航一起切换。

## 原因与修复

此前主会话在 `MainLayout` 中绘制主导航，其他页面在各自的 `ProductScaffold` 中再次绘制导航；点击入口会 `push` 一个包含整套导航的新路由。页面过渡包含侧栏，并且反复切换会累积页面栈。

现在由 `ProductWorkspace` 常驻承载唯一主导航。传输、文件和设置各自拥有保留状态的内容导航栈，首次访问后持续挂载。文件和设置的二级栏放在内容 Navigator 外部，详情页动画只影响右侧内容。一级切换直接选择对应分区，不创建整页路由；二级入口回到该分区根页后打开目标，避免重复压栈。

- 保留传输引擎、选中会话、草稿，以及文件页的搜索和滚动状态。
- 文件、设置和偏好页的入口通过工作区统一分发；跨分区跳转不再将文件页面压入设置内部。
- 系统返回只处理当前可见分区，隐藏分区不能响应返回并误弹出自己的根页。
- 桌面/窄屏转换复用同一批页面，分别显示固定侧栏或底部入口。
- 隐藏页面取消文件粘贴快捷键注册；读取剪贴板期间切换页面也不会把文件送进错误的页面。
- 账号服务集群切换、删除本机等需要整体重置的流程仍明确使用根 Navigator。
