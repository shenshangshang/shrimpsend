## 关键行为与本轮修复

- Web 连接、会话与草稿由持续存在的工作区承载，切到文件或设置不会主动销毁连接；语言切换不刷新整页。
- 接收沿用直接写目标目录方案。Mac 保留用户已选择的目录；支持目录选择的浏览器直接写授权目录，否则交给浏览器下载，并如实显示状态。
- Flutter WebDAV 本机连接不依赖账号；元数据本机保存，密码进入系统安全存储。退出账号仅清理本应用对应凭据，不清空系统钥匙串。
- macOS 安全存储使用登录钥匙串兼容配置，修复未配置 Keychain Sharing 的本地构建不能保存连接的问题。依据：[插件 macOS 配置说明](https://pub.dev/packages/flutter_secure_storage)。
- WebDAV OPTIONS 兼容 204 等成功响应，覆盖连接探测、上传前探测、字节下载、流式下载；403/503 仍按错误处理，原有临时失败重试保留。
- Mac 云端页旧底部导航合并为页内标签和上传按钮，避免与全局三入口重复。
- 修复 Flutter 页面销毁时读已失效 provider、后台更新失败覆盖整个页面，以及深色选中标签对比度。
- 修复 Web 后台额度查询在服务重启时的未处理异常；离线保留上次额度，联网后重新查询，发送仍由服务端校验。
- 订单接口仅返回当前账号最近 100 笔；设备身份不得读取。套餐目录允许游客访问。
- 修复手机文件任务表格溢出、通用设置名称输入宽度、云端上传后列表刷新、任务筛选混入已完成记录和授权请求竞态。
